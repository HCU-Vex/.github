## Who We Are

Holecounters United (HCU) is a competitive VEX V5 robotics organization built around one goal: **winning everything**. We compete across all pillars of the competition — Autonomous Skills, Driver Skills, Notebook, and Tournament — and we share the tools we build along the way.

This GitHub is our open-source hub. If you're a VEX team looking for solid, match-tested code, you're in the right place.

## 🤝 Contributing

We welcome contributions from the VEX community. Here's how to get involved:

1. **Fork** the repo you want to contribute to
2. **Create** a branch for your feature or fix
3. **Submit** a pull request with a clear description
4. **Join the discussion** in Issues — feedback, ideas, and bug reports all welcome

Please read each repo's `CONTRIBUTING.md` before submitting.
